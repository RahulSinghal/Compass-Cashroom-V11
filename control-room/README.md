# Control Room — Engagement Strategist Hub

Project communication and tracking hub for the CashRoom Compliance System (Phase 2).

**Audience**: Engagement strategist, delivery lead, client stakeholders.
For technical/engineering docs, see `../codebase/`.

## Folder Structure

| Folder | Purpose | Who Writes |
|---|---|---|
| `requirements/` | Finalized requirements, specs, process docs | Engagement Lead, Client |
| `planning/` | Phase plans, build approach, milestones, implementation summaries | Engagement Lead, Dev Lead |
| `progress/` | Daily status updates, sprint summaries | Dev Lead, AI Engineer |
| `gap-analysis/` | Engagement-level coverage and risk summaries | Engagement Lead |
| `open-items/` | Pending questions, blockers, action items with owners and due dates | All |
| `meeting-notes/` | Dated notes from client calls and internal syncs | Engagement Lead |
| `client-comms/` | Key client messages, approvals, clarifications | Engagement Lead |
| `change-log/` | Scope changes, requirement amendments, CR tracking | Engagement Lead |
| `sign-offs/` | Client approvals on milestones, UAT sign-offs | Engagement Lead, Client |

## Naming Convention

- Files: `YYYY-MM-DD_short-description.md`
- Example: `2026-03-25_phase2-kickoff-notes.md`
